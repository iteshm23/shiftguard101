The Challenge

Distribution Shift

Ptrain(x) ≠ Ptest(x). Test images come from a different capture pipeline. The metric is Macro F1 — not accuracy — which penalises poor minority-class recall.

What fails

Standard cross-entropy ignores class frequency. The model memorises the majority class texture pattern and fails on shifted test images and minority classes.

Our approach

Balanced Softmax loss + AutoAugment + MixUp/CutMix + SWA + 3-seed ensemble + 31-view TTA — each technique addresses a different failure mode.

Architecture

WideResNet-28-10

Best CIFAR-scale backbone without pretraining. 3×3 stem preserves spatial resolution on 32×32 inputs. ~36.5M parameters.

Loss Function

Balanced Softmax

Incorporates class frequency into the softmax denominator so minority classes receive proportionally larger gradient signal.

p(c | x) = n_c · exp(f_c) / Σⱼ nⱼ · exp(fⱼ)

≡ add log(n_c) to class-c logit → standard cross-entropy

vs. LDAM

LDAM requires a two-phase DRW schedule (standard CE early, then margin loss). Balanced Softmax applies from epoch 1 — simpler and more stable.

vs. oversampling

Oversampling repeats examples without changing the loss geometry. Balanced Softmax shifts decision boundaries mathematically — no duplicated data.

Augmentation Strategy

AutoAugment + MixUp + CutMix

1
AutoAugment (CIFAR10 policy) 25 sub-policies learned via RL search — Rotate, Equalize, Color, Sharpness…
2
Random Crop + Flip 4-pixel padding, p=0.5 horizontal flip
3
Cutout Zero-mask a random 16×16 patch → occlusion robustness
4
MixUp / CutMix (50/50) λ ~ Beta(1,1) — texture-agnostic interpolation regularisation

MixUp/CutMix disabled during SWA phase (epoch 225→300) to stabilise weight averaging.

Optimisation

Cosine LR Warmup + SWA

Nesterov SGD

lr = 0.1, momentum = 0.9, weight decay = 5e-4.
5-epoch linear warmup → cosine decay to epoch 225.
Gradient clipping: max_norm=5.0.

Stochastic Weight Averaging

From epoch 225: weights averaged at constant SWA lr = 0.005. After training: BN stats recomputed. Finds flat loss minima for better test generalisation.

  • Why Nesterov SGD over Adam? Adam empirically underperforms WRN on CIFAR — SGD with momentum finds better-generalising minima for this architecture.
  • Why cosine + warmup? Warmup prevents divergence from large initial Balanced Softmax adjustments; cosine gives smooth monotone LR decay.
Inference Strategy

3-Seed Ensemble + 31-View TTA

3-Seed Ensemble

Seeds {42, 7, 13} → 3 independent WRN-28-10 models. Different initialisations converge to different local minima. Averaging class probabilities reduces prediction variance.

Ensemble error ≈ ε · [1 − (1−ρ)(K−1)/K], ρ≈0.6 for deep nets.

31-View TTA

1 clean pass + 30 stochastic views (RandomCrop + HFlip + Rotation(15°) + ColorJitter). Arithmetic mean of probability vectors before argmax.

Approximates ET[p(y|T(x))] — expected probability under the test augmentation distribution.
